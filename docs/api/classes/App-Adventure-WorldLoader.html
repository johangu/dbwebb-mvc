WorldLoader.php : 23

Loads the pirate adventure into the database.

All content of the game, rooms, passages, items, hotspots and interactions, is defined here and written to the database through the ORM. Loading the world clears the world tables first, so it can also be used to reset the database. The highscores are kept, since they are not part of the world.
